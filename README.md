# Microsoft 365 Copilot Chat: Prompting y productividad aplicada

Curso con progresión de nivel básico a intermedio. La sesión se desarrolla sobre un mismo caso ficticio de inversiones y finanzas que evoluciona mediante la construcción, refinamiento y validación de prompts cada vez más precisos. Los resultados de cada práctica se incorporan progresivamente a una misma Copilot Page.

## Lista de laboratorios

### Capítulo 2

- [Práctica guiada 1. Crear el prompt base para resumir una oportunidad de inversión ficticia para una audiencia ejecutiva](Capitulo02/README.md#práctica-guiada-1-crear-el-prompt-base-para-resumir-una-oportunidad-de-inversión-ficticia-para-una-audiencia-ejecutiva)
  - Descripción: Construir un prompt base a partir del caso ficticio NexoSolar, definiendo objetivo, contexto, audiencia, evidencia, restricciones y formato esperado. El participante ejecutará su propia versión, la comparará con un prompt sugerido y un resultado de referencia, realizará los ajustes necesarios y conservará el resultado validado como primera sección de una Copilot Page acumulativa.
  - Duración estimada: 15 min
  - [Ver capítulo completo](Capitulo02/README.md)

### Capítulo 3

- [Práctica guiada 2. Evolucionar el prompt base hasta obtener un brief ejecutivo con tesis, supuestos, riesgos y datos faltantes](Capitulo03/README.md#práctica-guiada-2-evolucionar-el-prompt-base-hasta-obtener-un-brief-ejecutivo-con-tesis-supuestos-riesgos-y-datos-faltantes)
  - Descripción: Evolucionar el prompt y el resumen obtenidos en la práctica anterior para generar un brief ejecutivo que diferencie hechos, supuestos e inferencias, organice los riesgos y priorice los datos faltantes. El participante comparará su construcción con un prompt sugerido y un resultado esperado antes de incorporar el brief validado a la misma Copilot Page.
  - Duración estimada: 25 min
  - [Ver capítulo completo](Capitulo03/README.md)

### Capítulo 4

- [Práctica guiada 3. Ampliar el caso comparando dos alternativas de inversión y construir una matriz ejecutiva de criterios, riesgos y preguntas pendientes](Capitulo04/README.md#práctica-guiada-3-ampliar-el-caso-comparando-dos-alternativas-de-inversión-y-construir-una-matriz-ejecutiva-de-criterios-riesgos-y-preguntas-pendientes)
  - Descripción: Incorporar la alternativa ficticia GridFlex y construir un prompt que permita comparar ambas oportunidades mediante criterios comunes. El participante diferenciará hechos, inferencias, cálculos derivados y datos no disponibles, validará la matriz obtenida y consolidará los riesgos y preguntas pendientes en la Copilot Page acumulativa.
  - Duración estimada: 25 min
  - [Ver capítulo completo](Capitulo04/README.md)

### Capítulo 5

- [Práctica guiada 4. Caso final: convertir el análisis acumulado en una recomendación ejecutiva, justificarla, identificar riesgos y preparar preguntas de seguimiento](Capitulo05/README.md#práctica-guiada-4-caso-final-convertir-el-análisis-acumulado-en-una-recomendación-ejecutiva-justificarla-identificar-riesgos-y-preparar-preguntas-de-seguimiento)
  - Descripción: Utilizar el análisis acumulado para construir un prompt de recomendación ejecutiva provisional sobre NexoSolar y GridFlex. El participante deberá justificar la conclusión con evidencia disponible, identificar riesgos y datos pendientes, establecer condiciones para avanzar, formular preguntas de seguimiento y consolidar la Copilot Page como entregable final del caso.
  - Duración estimada: 40 min
  - [Ver capítulo completo](Capitulo05/README.md)
