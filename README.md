# Microsoft 365 Copilot Chat: Prompting y productividad aplicada

Curso con progresión de nivel básico a intermedio. La sesión se desarrolla sobre un mismo caso de inversiones y finanzas que evoluciona mediante prompts cada vez más precisos.

### Capítulo 3

- [Práctica guiada 2. Evolucionar el prompt base hasta obtener un brief ejecutivo con tesis, supuestos, riesgos y datos faltantes](Capitulo03/README.md#práctica-guiada-2-evolucionar-el-prompt-base-hasta-obtener-un-brief-ejecutivo-con-tesis-supuestos-riesgos-y-datos-faltantes)
  - Descripción: Evolucionar el prompt base del capítulo anterior incorporando contexto, audiencia, formato, restricciones y criterios de calidad hasta obtener un brief ejecutivo con tesis, supuestos, riesgos y datos faltantes.

### Capítulo 4

- [Práctica guiada 3. ### Capítulo 5

- [Práctica guiada 4. Caso final: convertir el análisis acumulado en una recomendación ejecutiva, justificarla, identificar riesgos y preparar preguntas de seguimiento](Capitulo05/README.md#práctica-guiada-4-caso-final-convertir-el-análisis-acumulado-en-una-recomendación-ejecutiva-justificarla-identificar-riesgos-y-preparar-preguntas-de-seguimiento)
  - Descripción: Integrar las técnicas de prompting sobre el mismo caso para convertir el análisis acumulado en una recomendación ejecutiva, justificarla, identificar riesgos y preparar preguntas de seguimiento mediante varias iteraciones hasta obtener un resultado final reutilizable.
