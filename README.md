# Microsoft 365 Copilot Chat: Prompting y productividad aplicada

## Plataforma de laboratorios

Te damos la bienvenida a la plataforma de laboratorios del curso Microsoft 365 Copilot Chat: Prompting y productividad aplicada. Aquí construirás, refinarás y validarás prompts para un caso de inversiones y finanzas que evoluciona durante las prácticas. Los resultados se consolidarán progresivamente en una misma Copilot Page.


## Lista de laboratorios

Cada uno de estos laboratorios está diseñado para ofrecerte una experiencia práctica. Haz clic en los enlaces para comenzar y realiza las actividades en el orden indicado.

## Capítulo 2

### [Práctica guiada 1. Crear el prompt base para resumir una oportunidad de inversión ficticia para una audiencia ejecutiva](Capitulo02/README.md)

- Descripción: Construye un prompt para resumir la oportunidad de inversión NexoSolar, definiendo objetivo, contexto, audiencia, evidencia, restricciones y formato. Compara el prompt y la respuesta con las referencias y conserva el resultado validado en una Copilot Page.
- ⏱️ Duración estimada: 15 min.

## Capítulo 3

### [Práctica guiada 2. Evolucionar el prompt base hasta obtener un brief ejecutivo con tesis, supuestos, riesgos y datos faltantes](Capitulo03/README.md)

- Descripción: Refina el prompt anterior para obtener un brief ejecutivo que distinga hechos, supuestos e inferencias, organice riesgos y priorice datos faltantes. Revisa el resultado e incorpora el brief validado a la misma Copilot Page.
- ⏱️ Duración estimada: 25 min.

## Capítulo 4

### [Práctica guiada 3. Ampliar el caso comparando dos alternativas de inversión y construir una matriz ejecutiva de criterios, riesgos y preguntas pendientes](Capitulo04/README.md)

- Descripción: Incorpora la alternativa GridFlex y compara ambas oportunidades mediante criterios comunes. Construye y valida una matriz ejecutiva que diferencie evidencia, inferencias y datos no disponibles, y agrega riesgos y preguntas pendientes a la Copilot Page.
- ⏱️ Duración estimada: 25 min.

## Capítulo 5

### [Práctica guiada 4. Caso final: convertir el análisis acumulado en una recomendación ejecutiva, justificarla, identificar riesgos y preparar preguntas de seguimiento](Capitulo05/README.md)

- Descripción: Integra el resumen, el brief y la matriz comparativa en una recomendación ejecutiva provisional. Justifica la conclusión con evidencia, identifica riesgos y condiciones para avanzar, formula preguntas de seguimiento y consolida la Copilot Page final.
- ⏱️ Duración estimada: 40 min.
